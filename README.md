# Osobní portfolio

Osobní portfolio vytvořené pro prezentaci mých projektů, dovedností a zkušeností.

## Použité technologie

- HTML
- CSS
- JavaScript
  
## Funkce

- Responzivní design
- Přepínání mezi češtinou a angličtinou
- Jednostránková SPA navigace
- Kontaktní modal
- Dynamické zobrazování projektů a dalších informací
